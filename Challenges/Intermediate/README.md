# AI vs Non-AI Coding Challenges

Welcome to the coding assessment.

This repository contains two folders:

- `Non-AI`
- `AI`

Each folder contains coding challenges designed to assess performance under different conditions.

Please read the instructions carefully before starting.

---

# Order of Completion

You may complete the challenges in either order.

However, once you begin a challenge from one folder, you must complete it under the rules specified for that folder.

---

# Non-AI Challenges

## Restrictions

While completing challenges inside the `Non-AI` folder:

You are **NOT permitted** to use:

- ChatGPT
- GitHub Copilot
- Google Gemini
- Claude
- Any AI-powered code generation tool
- Any large language model
- Any automated code completion tools that generate logic

You **ARE permitted** to use:

- Official documentation (e.g., Microsoft Docs)
- Stack Overflow
- Textbooks or lecture notes
- Standard search engines
- Your IDE
- Built-in IntelliSense (non-generative)

The expectation is that all logic and implementation are written manually by you.

---

# AI Challenges

## Permissions

While completing challenges inside the `AI` folder:

You are permitted to use:

- ChatGPT
- GitHub Copilot
- Google Gemini
- Claude
- Any generative AI tool
- AI-assisted code completion tools

You may use AI as much or as little as you choose.

You are still responsible for:

- Understanding the solution
- Ensuring the program runs correctly
- Submitting working code

---

# General Rules

- Do not copy solutions between folders.
- Treat each challenge independently.
- Do not modify method signatures unless explicitly instructed.
- All challenges must compile and run.

---

# Academic Integrity

By participating, you agree to follow the rules associated with each challenge condition.

Failure to follow the restrictions may invalidate your results.

---

Good luck.
