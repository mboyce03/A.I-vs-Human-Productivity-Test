# Intermediate Coding Challenge – Login Attempt Analyzer

## Objective

Analyse login attempt data to identify suspicious user behaviour using time-based logic.

---

## Task Description

You are given a list of login attempts.  
Each login attempt contains:
- A username
- A timestamp

A user is considered **suspicious** if they have made **three or more login attempts within any rolling 10-minute window**.

Your task is to identify all suspicious users.

---

## Requirements

- Login attempts may not be in chronological order
- A user may appear multiple times
- Each suspicious user should appear only once in the result
- The result should be returned in alphabetical order
