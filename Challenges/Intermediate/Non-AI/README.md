# Intermediate Coding Challenge (Non-AI Assisted)

## Objective

Assess the ability to apply conditional logic and maintain state across a sequence of operations in C#, without the use of AI-based assistance.

---

## Task Description

You are given a list of bank account transactions represented as integers.

- A **positive value** represents a deposit
- A **negative value** represents a withdrawal

The account has the following rules:

- The balance starts at **0**
- A withdrawal is only allowed if it does **not** cause the balance to go below 0
- If a withdrawal would cause the balance to become negative, it is ignored

Your task is to calculate the **final account balance** after all valid transactions have been processed.

---

## Requirements

- Complete the task using the provided starter code
- Do not use AI-based coding assistance
- Do not change the method signature
- Process transactions in the order they appear
