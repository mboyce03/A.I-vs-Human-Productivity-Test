# Advanced Coding Challenge – Order Scheduling

## Objective

Apply multi-criteria decision logic to correctly schedule a set of tasks using C#.

---

## Task Description

You are given a list of customer orders.  
Each order contains the following information:

- An order ID
- A processing time (in minutes)
- A priority value (1 represents the highest priority)

Orders must be scheduled according to these rules:

1. Orders with higher priority are processed first
2. If two orders have the same priority, the order with the shorter processing time is processed first

Your task is to return the ordered list of order IDs based on these rules.

---

## Requirements

- Orders may be provided in any order
- Do not modify the provided data structures
- Do not change the method signature
- Focus on correctness and clear logic
