# Beginner Coding Challenge (Non-AI Assisted)

## Objective

Assess basic programming ability in C# without the use of AI-based assistance.

---

## Task Description

You are given a list of integers representing daily temperature changes.

A value is considered **positive** if it is **greater than 0**.

Your task is to count how many positive values exist in the list.

---

## Requirements

- Complete the task using the provided starter code
- Do not use AI-based coding assistance for this task
- Do not change the method signature
- Do not modify the original list
